Bine ați venit pe **`iDominiqe` (`idominiqe.com`)** — platforma centrală de documentație, blog tehnic și proiecte construită pe **Astro + Starlight** cu interfață **VisionOS smoked glass**.

## Caracteristici Principale

1. **Bară de Adresă Spațială**: Afișează ruta curentă, butoane Înapoi / Înainte, navigare rapidă prin URL, reîmprospătare animații (`↻`) și lansator Theme Studio.
2. **Vremea în Chișinău & Chat Live Telegram**: Pagina principală integrează prognoza live pentru Chișinău și un chat bidirecțional conectat la Telegram prin Cloudflare Worker (`idomi-tg-chat`).
3. **Suport Bilingv (EN / RO)**: Limba principală este **Engleza** (`/`), iar versiunea completă în **Română** este disponibilă sub `/ro/` cu comutator rapid `EN | RO` în antet.
4. **Subdomenii Independente**: [`portfolio.idominiqe.com`](https://portfolio.idominiqe.com/) (`iDominiqe/portfolio`) și [`v-2.idominiqe.com`](https://v-2.idominiqe.com/) (`iDominiqe/v-2`) rulează separat pe propriile ramuri și DNS.
